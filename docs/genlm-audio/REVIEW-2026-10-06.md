# Gen-Audio limits and readiness — 2026-10-06

Gen-Audio is the product. These controls live in this repository. Nothing here starts another project's actors, and importing `gen_audio` does not open a socket.

Python is `>=3.14,<3.15`. The 14 tests are `tests/test_guards.py`. They do not load torch or model weights.

## Where the controls run

| Control | Code |
| --- | --- |
| Utterance 8 000, segment 4 000 (ceiling 8 000), 64 segments (ceiling 128), script 20 000, prompt 8 000. Env may tighten, not raise the ceiling. | `gen_audio.guards`, applied by `gen_audio.cast.parse_script` and the Rust harness parser |
| `output_format` is `wav` or `mp3` | `normalize_output_format` |
| Podcast bytes stay inside the output directory | `write_bytes_exclusive` |
| Voice wavs stay inside the voices directory; a symlink that leaves it is rejected | `resolve_voice_file` |
| Model directories stay under `GENAID_MODEL_BASE` | `resolve_model_directory`, called from kokoro path resolution when that variable is set |
| Temp audio uses `mkstemp`, closes the descriptor, and unlinks in `finally` | `materialize_temp_audio` |
| Disk work and unload leave a running event loop | `gen_audio.gateway.run_off_loop` |
| Generate holds one lock | `synth_kokoro_onnx._MODEL_LOCK` |
| Optional `SHA256SUMS` or `GENAID_MODEL_SHA256_FILE`; `GENAID_REQUIRE_MODEL_CHECKSUM=1` fails closed; `GENAID_LOCAL_FILES_ONLY=1` rejects URL paths | `verify_model_checksums`, `local_files_only_enabled` |
| Timeout 504, unreachable 503, upstream 4xx forwarded, other HTTP 502. The log line is status and exception type, not a prefix of the user text. | `classify_upstream_failure`, `tts_proxy_error` |
| `GET /genaid-audio/health` is liveness and stays 200 when the model is unloaded. `GET /genaid-audio/ready` is readiness. A missing speech backend is HTTP 200 on health and 503 on the gateway ready check. | `gen_audio.serve`, `gen_audio.node_http`, `gen_audio.gateway` |

vLLM client timeout defaults to 120 seconds and cannot exceed 600 (`vllm_timeout_seconds`).

## Still open on purpose

- Chunk long scripts, synthesize under the lock, resample to 24 kHz, and crossfade. The caps do not split one GPU call.
- Output loudness (integrated LUFS and a true-peak ceiling).
- Real MP3 encoding. `mp3` is an allowed name. This package does not claim a bitstream encoder.
- Authentication on the node route.
- Cancelling a generate that has already started. A timeout must not be described as if the worker stopped.

## What this review is not

The in-window spectrogram is a browser drawing of a fixture tone. The Python matplotlib panel is the spectrogram this package writes. Inverse-HDR cube revision is a heuristic, not a quality gate. VibeVoice, PersonaPlex, and Gradio are compare-list names. This package does not vendor them.
